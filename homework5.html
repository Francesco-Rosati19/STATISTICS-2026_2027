Ex 1: Riemann vs. Lebesgue Integration

1. Two Views of the Integral

The fundamental difference between the two integration theories lies in how they partition space:

Riemann (Domain Partition)

Slices the X-axis (domain) into subintervals Δx. Calculates area by multiplying interval width by function height f(xᵢ).

∫ f(x) dx ≈ Σ f(xᵢ*) · Δx

Lebesgue (Range Partition)

Slices the Y-axis (range) into sets Yⱼ. Groups all domain points mapping to a specific level, computing the "measure" μ of that preimage.

∫ f dμ ≈ Σ yⱼ · μ( f⁻¹(yⱼ) )

2. Accuracy, Convergence & Efficiency

Accuracy & Convergence: For standard Riemann-integrable functions (like sin(x) or x²), both approaches converge to the exact same value. Riemann converges as O(1/N). Lebesgue convergence depends on both the domain sampling resolution (N) and the number of range bins (M).

Computational Efficiency: Riemann is highly efficient, operating in O(N) time. The numerical Lebesgue approach is heavier: it requires evaluating N points and then binning/sorting them into M range levels, introducing additional memory and processing overhead.

3. Pathological Functions (Where they differ)

The Dirichlet Function: f(x) = 1 if x is Rational, 0 if x is Irrational Because every subinterval contains both rational and irrational numbers, Riemann upper and lower sums oscillate endlessly between 1 and 0. It is Not Riemann-Integrable. However, since rational numbers have a Lebesgue measure of 0, the Lebesgue integral flawlessly evaluates to 0.

Ex 2: Numerical Computation of the Normal CDF

1. Liouville's Theorem & The Integration Limit

The Cumulative Distribution Function (CDF) of the Standard Normal Distribution represents the accumulated area under the Gaussian curve:

Φ(x) = (1 / √(2π)) ∫ e^(-t²/2) dt     [from -∞ to x]

According to Liouville's Theorem (1835), the antiderivative of e^(-t²) cannot be expressed using any finite combination of elementary functions. We cannot solve this algebraically.

2. The Role of the Error Function (erf)

To bypass Liouville's restriction, mathematicians defined a "Special Function" called the Error Function (erf), providing an exact analytical representation:

erf(z) = (2 / √π) ∫ e^(-t²) dt     [from 0 to z]
Φ(x) = ½ [ 1 + erf(x / √2) ]

However, declaring a special function doesn't give a computer a way to calculate it natively. We must rely on numerical methods (Integration, Series, or Approximations) to evaluate it.

3. Analysis of Numerical Methods

Simpson's Rule

Integrates the PDF numerically using parabolic arcs. Highly accurate but computationally heavy O(N). Used as our baseline reference.

Taylor Series

Infinite power series expansion of erf. Fast for small x O(terms), but suffers from floating-point cancellation for large x.

Polynomial Approx.

Abramowitz & Stegun formula. Extremely efficient O(1) constant time, guaranteeing max error ≤ 1.5 × 10⁻⁷ everywhere.
